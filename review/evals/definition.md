# Rubric: definition

For the element's definition paragraph, answer each question. Fail if any answer is no.

1. Does it say what the element *is*, in words other than the element's own name?
2. Could a reader who knows none of the source models tell an item of this element from an item of its nearest neighbour (e.g. REQUIREMENT from STANDARD)?
3. Does every attribute with an empty Meaning cell have a meaning obvious from its name alone?
4. Where a guidance line applies (e.g. a core job's statement is solution-free), does the definition agree with it?

Quote the definition as evidence.
