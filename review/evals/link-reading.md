# Rubric: link-reading

For each row of the element's Links table, read "<ELEMENT> <verb> <Target>" as a sentence (e.g. "PROCEDURE operationalizes CONTROL"). Fail if any answer is no.

1. Is the sentence true of every item, read with the link's cardinality ("every procedure operationalizes exactly one control")?
2. Does it point from the dependent item to its anchor: would the target still make sense if the source were deleted?
3. Is the verb a single action verb a practitioner of the source model would recognise?

Quote the row.
