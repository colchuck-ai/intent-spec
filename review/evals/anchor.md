# Rubric: anchor

Read the element's `Anchor:` line, then the source model's own definition of the named term (c4model.com, DFD3, ComplianceForge HCGF, the JTBD literature; cite the page). Fail if any answer is no.

1. `exact`: does the source define the same thing, with the same relationships the model draws?
2. `close`, `broad`, `narrow`, `related`: is that the right word for the difference, and does the line say what differs?
3. `added`: is it true that no anchored source model has this element?
4. Does the element change one of the source model's own elements or relationships (removes, merges, redefines, retypes a link, derives a stored link) without saying `departure`?

Quote the Anchor line and the source's definition.
