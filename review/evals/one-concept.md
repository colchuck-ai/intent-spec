# Rubric: one-concept

Compare the element's definition and attributes with every other element's (INV-12: each concept exists once). Fail if any answer is no.

1. Is there no other element whose definition describes the same thing in different words?
2. Where two elements are deliberately separate (e.g. DFD elements and the C4 elements they represent), does one of them say how they differ?
3. Is there no attribute on this element that duplicates a link or attribute elsewhere (the same fact stored twice)?

Quote both definitions when two elements overlap.
