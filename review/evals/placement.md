# Rubric: placement

For each rule and derivation listed under the element, answer each question. Fail if any answer is no.

1. Is this element the one the rule is checked from: the element whose items the rule's statement starts from ("every ratified requirement…" is checked from REQUIREMENT)?
2. If the rule spans several elements equally, would the area's top-level Rules list be no better a home?

Then for the element itself:

3. Does it belong to the area it sits in, judged by which source model or discipline it comes from?

Quote the rule and the element it should move to, if any.
