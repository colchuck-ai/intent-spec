# Review

An expert panel reviews intent-spec through example documents, and the accepted findings are applied to the model. Beads tracks every round, and subagents do the work.

- `loop.md`: how a round runs, for the orchestrator, reviewers, triage, fixers and humans
- `prompt.md`: the shared review prompt
- `personas/`: the 13 reviewer profiles
- `examples/`: the documents the panel reviews
- `.beads/formulas/review-round.formula.toml`: the round template
